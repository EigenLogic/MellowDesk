# MellowDesk Community Code of Conduct

MellowDesk is built around calm, respectful support. We expect the same tone in issues, reviews, discussions, and other project spaces.

## Expected behavior

- Be respectful, patient, and specific.
- Critique ideas and code without attacking people.
- Welcome different experience levels and backgrounds.
- Accept correction, clarify misunderstandings, and give others room to improve.
- Protect privacy, especially around camera images, health-related context, and personal history.
- Keep discussions relevant to the project and its users.

## Unacceptable behavior

- Harassment, threats, discrimination, intimidation, or demeaning language.
- Unwanted sexual attention or imagery.
- Publishing another person's private information without permission.
- Sharing identifiable camera material or sensitive user data.
- Deliberate disruption, spam, impersonation, or retaliation after a report.

## Scope

This code applies in repository issues, pull requests, reviews, discussions, release feedback, and public spaces where someone represents the project.

## Enforcement

Maintainers may edit or remove content, close discussions, reject contributions, issue a warning, or temporarily or permanently restrict participation. Responses should be proportionate to the behavior, its impact, and whether it is repeated.

To report conduct privately, use the private contact method published on the profile of the organization hosting this repository. If no private method is visible, open a minimal issue asking for a private maintainer contact without including incident details. Reports will be handled as confidentially as practical, and retaliation is not permitted.
