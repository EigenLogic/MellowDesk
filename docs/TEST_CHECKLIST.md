# 小桌伴 MellowDesk：Beta 真人验收清单

本清单是公开 Beta 的真人放行门槛。先由开发检查生成待发布的签名 App；随后必须在至少一台真实 Mac 上完成工作间歇、真实后台更新与安装验收，并在 MacBook 前置摄像头上完成颈肩计数验收。自动化测试或只改版本号的模拟不能替代这些步骤。

## 工作间歇与提醒

1. 首次启动允许通知，确认菜单栏可直接进入颈肩微运动、提肛跟练、喝水打卡和起身活动。
2. 完成一次起身活动和一次喝水打卡，确认今日次数、近期完成和 7 / 30 天统计分别增加，且不会重复记账。
3. 确认下一提醒按“起身 → 补水 → 颈肩”轮换；推迟保留当前项目，完成或“跳过本次”后推进。
4. 展开菜单栏面板跨过一分钟边界，确认“下次提醒”倒计时自动减少一分钟。
5. 到点后确认提醒卡锚定在状态栏叶片下方；切换到其他 App 并等待至少 10 秒，卡片仍不消失。
6. 分别从提醒卡验证“开始”“推迟 10 分钟”和“今天暂停”；开始后对应跟练面板锚定在状态栏下方并保持在其他 App 前面，暂停后不应在暂停期内重新提醒。
7. 跟练中点击状态栏图标收起并再次展开，确认进度保留；点击“跳过本次”后不新增完成记录，且下一提醒进入轮换中的下一项。

## 颈肩摄像头流程

1. 从菜单栏开始颈肩微运动，允许摄像头并保持正脸完成中立位校准。
2. 每项按提示先做一次不计数的方向适配动作。
3. 依次完成转头、侧屈、低头回正，确认三轴方向与动画提示一致，并记录 App 次数和实际次数。
4. 三项达标后确认摄像头灯熄灭，今日与近 7 / 30 天记录各增加一次。

期望：正常光线、单人完整入镜时，每项误差不超过 ±1 次；未回正、单帧晃动和只做到一半不应计数。

## 提肛跟练

1. 新安装或从 beta.3 升级后，确认菜单栏默认显示“开始 2 分钟提肛跟练”，设置页的“盆底肌练习”开关默认开启且无需隐藏操作解锁。
2. 完整跟随四段两分钟节奏，验证暂停、继续、跳过和再来一组；整个过程摄像头灯保持熄灭。
3. 完成或跳过后确认不新增任何完成记录；关闭跟练面板后，原有健康提醒节奏继续运行。
4. 在设置中关闭开关，确认菜单栏入口消失；重新开启后入口恢复。

## 更新与安装

1. Beta.4 是首个 Sparkle 种子版本；从 beta.3 覆盖安装 beta.4 时仍完成最后一次手动下载与安装，确认原正式版提醒设置和历史继续可读，设置页默认开启“自动下载并安装更新”。
2. 从下一版开始，或使用完整签名的 QA 更新链路，先把上一个公开 Sparkle 版本安装到 `/Applications`，写入可辨认的提醒设置并完成至少一条历史；不要用只改 `MellowDeskReleaseVersion` 的假升级代替。
3. 确认生产 appcast 已指向当前待验收的真实 GitHub Release ZIP。点击“现在检查”作为确定性触发，确认旧 build 在后台下载真实 ZIP，下载期间提醒、菜单栏和训练仍可使用；准备完成后才显示“安装并重启 / 稍后”，且全程没有打开浏览器或 GitHub 网页。
4. 选择“稍后”，确认提示关闭但已下载更新保留；退出小桌伴后等待安装完成，再次启动应显示新版本/build，并保留第 2 步的提醒设置和历史。
5. 在独立 QA 轮次重复旧 build → 新 build，选择“安装并重启”，确认旧进程退出、App 被替换并自动重启，版本/build、设置和历史均正确。
6. 断网重复一次手动检查，确认失败状态可理解且不影响提醒与训练；恢复网络后可重新检查。网络观察中只应出现 raw GitHub appcast 和 appcast 指向的 GitHub Release ZIP，不应包含分析、遥测或系统画像请求。
7. 从 GitHub Release 重新下载 ZIP 和 SHA-256 文件，校验 checksum、Developer ID、stapled ticket、Gatekeeper `accepted`、主程序与 Sparkle framework 的 `arm64 + x86_64`、最低 macOS 13，以及 `Installer.xpc` 的嵌套签名。

## 恢复与隐私

- 暂停、遮住脸或点击状态栏图标收起跟练面板：当前半次动作作废，摄像头灯在面板收起后熄灭。
- 重新展开跟练面板：摄像头重新开启，并从中立位开始当前动作，不丢失已完成次数。
- 拒绝摄像头：可改用手动计次并完成整组。
- 摄像头被其他 App 占用：显示可理解的失败提示，并可改用手动计次。
- 从系统设置补授权后回到 App：摄像头可在本次训练中恢复。
- 训练中检查磁盘：历史 JSON 根层只有存储版本与 session 列表；session 只包含 ID、开始/结束时间、状态、内容版本、是否使用摄像头及动作结果；动作结果只包含动作 ID、目标/完成次数与完成模式。不应出现照片、视频或逐帧角度文件。

## 放行结论

工作间歇、提醒、提肛跟练、真实后台更新与安装、恢复/隐私项全部通过，且三项颈肩动作计数误差均在 ±1 次内，才可将本轮用户测试标记为通过。Beta.4 作为首个种子版本按上述例外完成最后一次手装；从下一版起，旧 build → 新 build 是不可跳过的放行门槛。

## 反馈格式

请回复 macOS 版本、Mac 型号、三类工作间歇与提肛跟练结果、三轴方向是否正确、每项“实际次数 / App 次数”、旧/新 build、后台下载、安装方式、设置与历史保留结果，以及权限/占用/释放项。如果卡住，再附上所在页面、画面提示和是否看到摄像头绿灯。
