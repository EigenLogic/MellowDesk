# 小桌伴 MellowDesk：颈间模块真人验收清单

本清单是首个 Beta 的真人放行门槛。先由开发检查生成 `build/MellowDesk.app`；随后必须由真人在至少一台 MacBook 前置摄像头上完成以下验收。自动化合成序列不能替代这一步。

## 主流程

1. 首次启动允许通知，从菜单栏开始训练。
2. 允许摄像头，保持正脸完成中立位校准。
3. 每项按提示先做一次不计数的方向适配动作。
4. 依次完成转头、侧屈、低头回正，确认三轴方向与动画提示一致，并记录 App 次数和实际次数。
5. 三项达标后确认摄像头灯熄灭，今日与近 7 / 30 天记录各增加一次。
6. 展开菜单栏面板跨过一分钟边界，确认“下次提醒”倒计时自动减少一分钟。
7. 到点后确认提醒卡锚定在状态栏叶片下方；切换到其他 App 并等待至少 10 秒，卡片仍不消失。
8. 点击“开始 3 分钟微运动”，确认提醒卡关闭且训练窗口立即出现在最前面；另行验证“推迟 10 分钟”和“今天暂停”。

期望：正常光线、单人完整入镜时，每项误差不超过 ±1 次；未回正、单帧晃动和只做到一半不应计数。

## 恢复与隐私

- 暂停、遮住脸、最小化或隐藏 App：当前半次动作作废，摄像头灯在最小化或隐藏后熄灭。
- 恢复窗口：摄像头重新开启，并从中立位开始当前动作，不丢失已完成次数。
- 拒绝摄像头：可改用手动计次并完成整组。
- 摄像头被其他 App 占用：显示可理解的失败提示，并可改用手动计次。
- 从系统设置补授权后回到 App：摄像头可在本次训练中恢复。
- 训练中检查磁盘：历史 JSON 根层只有存储版本与 session 列表；session 只包含 ID、开始/结束时间、状态、内容版本、是否使用摄像头及动作结果；动作结果只包含动作 ID、目标/完成次数与完成模式。不应出现照片、视频或逐帧角度文件。

## 放行结论

主流程与恢复/隐私项全部通过，且三项动作的计数误差均在 ±1 次内，才可将本轮用户测试标记为通过。

## 反馈格式

请回复 macOS 版本、Mac 型号、三轴方向是否正确、每项“实际次数 / App 次数”，以及权限/占用/释放项的结果。如果卡住，再附上所在动作、画面提示和是否看到摄像头绿灯。
