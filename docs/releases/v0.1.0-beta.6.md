# MellowDesk v0.1.0-beta.6 / 小桌伴 v0.1.0-beta.6

Release date / 发布日期: 2026-08-19

Status / 状态: public beta / 公开测试版

## Overview / 概览

Beta.6 keeps an active follow-along visible while you return to work. Neck, movement, hydration, and pelvic-floor activity popovers remain above ordinary app windows after MellowDesk loses focus, so an unfinished activity is not quietly buried behind another window.

Beta.6 让进行中的跟练在你切回工作时仍然可见。小桌伴失去焦点后，颈肩、起身、补水和盆底肌跟练会继续浮在普通 App 窗口之上，避免未完成活动被其他窗口悄悄遮住。

Pelvic-floor practice now also joins the regular rotation when enabled. Finishing the full two-minute guide adds one local completion to today's total, recent history, and per-activity 7/30-day statistics; skipping records nothing.

开启提肛跟练后，它现在也会进入常规轮换。完整练完两分钟会增加一条本地完成记录，并进入今日次数、近期完成和分类 7/30 天统计；跳过不会记账。

## Fixed / 修复

- Active activity popovers now use the macOS status-bar window level.
- When MellowDesk resigns active, it reasserts the existing popover's frontmost position without stealing keyboard focus or blocking the foreground app.
- The popover remains visible until completion or skip. Clicking the menu-bar icon still explicitly hides or restores the same in-progress activity.
- 活动 popover 现在使用 macOS 状态栏窗口层级。
- 小桌伴失去焦点后会重新确保现有 popover 位于最前，但不抢占键盘焦点，也不阻止操作当前 App。
- popover 会保持可见，直到完成或跳过；仍可点击菜单栏图标主动收起或恢复同一次跟练。

## Compatibility and privacy / 兼容性与隐私

Existing settings, reminder state, and completion history remain readable. The change adds no new permissions, network access, camera behavior, accounts, analytics, or telemetry.

原有设置、提醒状态和完成记录会继续保留。本次更新不新增权限、网络访问、摄像头行为、账号、分析或遥测。

## Validation / 验证

- 85 deterministic tests pass.
- Real-Mac acceptance passed by switching from an active exercise to another app and confirming that the popover remains above it through the completion screen.
- 85 项确定性自动测试通过。
- 真实 Mac 验收已通过：跟练中切换到其他 App，popover 仍保持在最前，且完成页也不被遮挡。

## Download and install / 下载与安装

The GitHub Release provides a notarized universal `arm64 + x86_64` archive and SHA-256 checksum. Existing beta.5 users can receive beta.6 through MellowDesk's signed in-app updater after the release appcast is activated.

GitHub Release 提供经 Apple 公证的 `arm64 + x86_64` 通用压缩包和 SHA-256 校验文件。签名 appcast 生效后，已安装 beta.5 的用户可通过小桌伴 App 内更新获取 beta.6。
