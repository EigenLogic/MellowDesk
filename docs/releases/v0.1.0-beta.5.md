# MellowDesk v0.1.0-beta.5 / 小桌伴 v0.1.0-beta.5

Release date / 发布日期: 2026-08-19

Status / 状态: public beta / 公开测试版

## Overview / 概览

Beta.5 keeps every follow-along where MellowDesk already lives: under the menu-bar icon. Neck, movement, hydration, and pelvic-floor activities no longer open separate activity windows. The active guide stays above other apps, can be hidden by clicking the menu-bar icon, and reopens with the same progress.

Beta.5 把所有跟练都收进小桌伴的菜单栏下拉区。颈肩、起身、补水和盆底肌跟练不再打开独立活动窗口；正在进行的引导会浮在其他 App 之上，点击菜单栏图标可暂时收起，再次打开时保留原有进度。

## Changed / 改进

- All four follow-along experiences share one sticky menu-bar popover instead of separate windows.
- Clicking the status icon hides or restores the same in-progress activity without resetting it.
- Every activity offers **Skip This Time**. A skip does not create completion history; when it came from a reminder, the plan advances to the next activity.
- 四类跟练统一使用一个置顶的菜单栏下拉区，不再分散到独立窗口。
- 点击状态栏图标可收起或恢复同一次跟练，不会重置进度。
- 所有跟练都提供“跳过本次”。跳过不写入完成记录；如果该活动来自提醒，计划会轮转到下一项。

## Automatic update test / 自动更新测试

Beta.5 is the first public update delivered to the Sparkle seed introduced in beta.4. With automatic updates enabled, beta.4 checks the signed appcast, downloads beta.5 in the background, verifies its EdDSA and Developer ID signatures, and offers **Install and Relaunch** or **Later** without opening a browser.

Beta.5 是首个向 beta.4 Sparkle 种子版推送的公开更新。开启自动更新后，beta.4 会读取签名 appcast，在后台下载 beta.5，验证 EdDSA 与 Developer ID 签名，然后在 App 内提供“安装并重启”或“稍后”，不会打开浏览器。

## Compatibility and privacy / 兼容性与隐私

Existing settings, reminder state, and completion history remain readable. Camera processing remains local and is used only during the neck routine. Update network access remains limited to the signed appcast and its referenced MellowDesk GitHub Release archive; Sparkle system profiling is disabled.

原有设置、提醒状态和完成记录会继续保留。摄像头处理仍只在颈肩跟练时在本机进行。更新网络访问仍仅限于签名 appcast 及其引用的 MellowDesk GitHub Release 压缩包；Sparkle 系统画像已关闭。

## Validation / 验证

- 81 deterministic tests pass locally and on Apple Silicon and Intel CI runners.
- The public archive is verified for SHA-256, strict code signature, Apple notarization, stapled ticket, Gatekeeper acceptance, nested Sparkle signatures, and `arm64 + x86_64` architectures.
- The beta.4-to-beta.5 in-app update is accepted on a real Mac before the release is considered complete.
- 81 项确定性自动测试在本地、Apple Silicon 和 Intel CI 上通过。
- 公开压缩包会复核 SHA-256、严格代码签名、Apple 公证、stapled ticket、Gatekeeper、Sparkle 嵌套签名与 `arm64 + x86_64` 架构。
- 在宣布发布完成前，会在真实 Mac 上验收 beta.4 到 beta.5 的 App 内更新。

## Known limitations / 已知限制

- The app UI is Chinese.
- Camera counting is approximate and may require manual counting when tracking is unavailable or unreliable.
- The routines are general work-break guidance, not diagnosis, treatment, or individualized rehabilitation.
- App 界面仍为中文。
- 摄像头计次是近似识别，跟踪不可用或不稳定时可使用手动计次。
- 所有练习都是一般工作间歇引导，不提供诊断、治疗或个体化康复方案。

## Download and install / 下载与安装

The GitHub Release includes a notarized universal archive and its SHA-256 checksum. Existing beta.4 users should receive this release through MellowDesk's in-app updater after the signed appcast is activated.

GitHub Release 提供经 Apple 公证的通用压缩包与 SHA-256 校验文件。已安装 beta.4 的用户在签名 appcast 生效后，应可直接通过小桌伴的 App 内更新获取本版。
