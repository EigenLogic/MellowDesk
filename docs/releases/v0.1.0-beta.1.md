# MellowDesk v0.1.0-beta.1

Release date: 2026-08-11

Status: public beta

## Overview

This is the first public beta of **MellowDesk (小桌伴)**. It includes one module: **NeckEase (颈间)**, a short animated neck-movement break with optional on-device camera counting and local completion history.

Hydration, stand-up, lunch, and takeout reminders are roadmap ideas and are not included in this release.

## Download

The GitHub Release provides a universal `arm64 + x86_64` macOS archive and its SHA-256
checksum. The app is signed by EigenLogic with Developer ID, uses Hardened Runtime, is
notarized by Apple, and includes a stapled notarization ticket.

## Included

- Native macOS menu-bar app for macOS 13 and later.
- Configurable weekdays, work hours, 30–90 minute reminder choices, sound, snooze, pause, and launch at login.
- Local notification actions to start a routine or snooze for 10 minutes.
- Three NeckEase movements:
  - slow left/right neck rotation, 4 repetitions per side;
  - gentle left/right lateral flexion, 3 repetitions per side;
  - gentle nod and return to neutral, 5 repetitions.
- Animated guidance and complete target-hold-return counting.
- Optional local Vision head-pose estimation with manual fallback.
- Adaptive 5–8° camera-recognition threshold for the gentle nod.
- Local daily, 7-day, and 30-day history.
- Clear-history, camera-permission, notification-permission, and launch-at-login controls.
- One-time workout-window recovery after the first macOS camera-permission prompt.

## Privacy

Camera frames and pose samples are processed in memory and are not recorded, saved, or uploaded. History contains only session summaries and movement results. This beta has no network entitlement, account, cloud sync, advertising, analytics, or telemetry integration.

Read [PRIVACY.md](../../PRIVACY.md) for the full data inventory and deletion controls.

## Build and test

Requirements:

- macOS 13 or later;
- a full Xcode installation compatible with Swift 5.10.

Build and open:

```bash
./Scripts/run_debug.sh
```

Run automated checks:

```bash
./Scripts/check.sh
```

The assembled source build is `build/MellowDesk.app` with bundle identifier `cn.eigenlogic.mellowdesk`.
Local source builds use ad-hoc signing; the downloadable GitHub Release is the official
Developer ID signed and notarized binary.

The repository contains 32 deterministic tests. The first beta also completed the
[real-camera checklist](../TEST_CHECKLIST.md) on a MacBook before release.

## Known limitations

- The app UI is Chinese.
- Camera counting is approximate and depends on lighting, framing, camera model, and individual movement.
- Manual counting may be needed when the camera is unavailable or recognition is unreliable.
- The release does not provide medical diagnosis, treatment, or individualized rehabilitation.
